Setup Instructions

  1. Get your Personal Access Token:
    Go to https://tempestwx.com/settings/tokens and create a new token.
  2. Find your Station ID:
    In the Tempest app or web dashboard, your Station ID is in the URL or station settings. It is a numeric ID (e.g., 12345).
  3. Find your Device ID:
    Your Tempest device ID can be found in station settings under "Devices". This is the specific Tempest unit ID (e.g., 67890).
  4. Set environment variables before starting the app: 
    export TEMPEST_TOKEN="your-token-here"
export TEMPEST_STATION_ID="your-station-id"
export TEMPEST_DEVICE_ID="your-device-id"
  5. Restart the app and visit this page again.

Alternative: Tempest UDP (Local Network)

If your Tempest is on the same local network, it broadcasts data via UDP on port 50222. This is a future enhancement option for real-time local data without requiring internet.

Alternative: Webhook

WeatherFlow also supports webhooks that push observation data to a URL you specify. Configure this in your Tempest app settings under "Integrations" to have data pushed to this app automatically.
